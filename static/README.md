# Clothing Store - Versión Estática Demo

Esta es una versión completamente estática (HTML/CSS/JS) del proyecto Clothing Store, creada para demostrar el diseño y la estructura visual sin dependencias de backend.

## Contenido

- `index.html` - Página principal con catálogo de productos
- `product.html` - Página de detalle de producto
- `styles.css` - Estilos completos del sitio
- `script.js` - Funcionalidades JavaScript básicas

## Características

✅ Diseño responsive
✅ Sidebar de filtros funcional
✅ Carrito de compras interactivo
✅ Animaciones suaves
✅ Footer premium con enlaces sociales
✅ Diseño minimalista y elegante

## Cómo usar

Simplemente abre `index.html` en tu navegador. No requiere servidor local ni dependencias adicionales.

## Nota

Esta versión es únicamente para demostración del diseño. Las imágenes están en rutas relativas (`../img/`) y requieren la estructura de carpetas del proyecto principal.
